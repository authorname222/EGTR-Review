# Data Card — EGTR-Review

## Sources
- **PeerRead** (Kang et al., 2018, NAACL) — BSD-3 License. Used: ICLR 2017–2018 reviews.
- **OpenReview** — Accessed via official API. Used: ICLR 2019–2020 papers. Not redistributed;
  see `scripts/build_full_dataset.sh` (released upon acceptance).

## Statistics (Full set, used in paper)
- Train: 997 papers
- Val:    60 papers
- Test:  329 papers
- Domain: Computer Science (ICLR), focused on ML / RL / NLP / CV

## Format
Each paper sample is stored as JSON:

```json
{
  "paper_id": "iclr2019_1234",
  "title": "...",
  "abstract": "...",
  "sections": [{"heading": "...", "paragraphs": [...]}],
  "citations": [{"ref_id": "...", "raw": "..."}]
}
```

**Note**: human review texts are **NOT** included in this sample directory. Full data
construction must be done locally; see `scripts/build_full_dataset.sh`.

## Leakage prevention
For evaluating evidence-groundedness, we explicitly filter OpenReview review texts,
rebuttals, and accept/reject decisions from the external retrieval results — see
`src/utils/leak_filter.py`.
